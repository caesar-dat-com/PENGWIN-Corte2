Fragmentos en este corte

Color: región anatómica. F: identificador predicho. El principal es la instancia de mayor volumen de cada región.

Máscaras predichas reconstruidas con marching cubes. Arrastra para girar y usa la rueda para acercar. Las etiquetas muestran las distancias de cada fragmento a su principal.

Cómo interpretar el resultado

Las distancias son aproximaciones EDT entre centros de vóxeles superficiales, calculadas con el espaciado físico. “Contacto 26” indica vecindad espacial; no es una evaluación clínica. La malla se simplifica solo para visualizar y no se usa para medir.

Los identificadores y las máscaras son predicciones: pueden contener regiones sobrantes, fusiones y fragmentos omitidos. Si no hay pares válidos con la referencia, el error de distancia aparece como “no evaluable”.
